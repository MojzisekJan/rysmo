# Rysmo

![Rysmo](docs/screenshot.png)

A 3D modeller for buildings, furniture and 3D printing. Draw on the model, push and
pull faces, and type exact sizes as you go. Runs on desktop and in the browser.
Written in Rust with Bevy and egui.

```sh
cargo run -p rysmo_app --release
```
