Rysmo
Editor GitHub

A 3D modeller for architecture

Buildings, rooms and furniture drawn to exact sizes. Draw on the model, push and pull faces, and type sizes as you go.

Open the editor Source code

Free, runs in the browser. Nothing to install.

Draw on the model

Lines and shapes snap to faces, edges and axes. Push and pull a face to give it depth.

Exact sizes

Type a length, an angle or a count while you draw. Measure and place guides with the tape.

Take it further

Export to OBJ, glTF, COLLADA and DXF, or to STL and 3MF for 3D printing.

Rysmo is free software under the GPL-3.0-or-later. Written in Rust with Bevy and egui.
